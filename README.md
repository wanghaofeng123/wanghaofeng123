## 实习与研究经历

### 多点生活（中国）网络科技有限公司 · 具身智能算法工程师实习
2026.06–2026.10

- **商超试吃分装与递交**。微调 π0.5 和 LingBot-VLA 2.0，在真机上评测目标位置和姿态变化时的抓取表现。分别尝试用热力图监督目标位置，以及用 VGGT 的几何特征做 Spatial Forcing 对齐。
- **人工纠正与策略训练**。搭建 DAgger 采集与训练流程，记录机器人自主执行和人工接管的片段。对比使用完整交互轨迹和只监督纠正片段两种训练方式，检查引入新示例后策略在原有场景中的表现。
- **世界动作模型与第一视角数据**。为 OpenWAM 组织视频训练窗口和有效监督掩码，研究动作监督对视频生成与动作预测的影响。针对商超第一视角视频，提取操作片段，用 MANO 重建三维手部轨迹，并把轨迹、视频帧和操作描述对齐。

### 中科第五纪智能科技有限公司 · 机器人算法工程师实习
2025.07–2025.10

- **抓取、摆放与开抽屉**。参与 VLA 监督微调和 DPO 偏好优化实验，完成推理部署与真机评测。在已测试的固定场景中，任务成功率约为 90%。
