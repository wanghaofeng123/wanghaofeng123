## 具身策略研究探索

**当杯子被移到示教范围之外，策略能否根据杯子与夹爪的相对位置，调整接近方向和闭爪时机？** 我想在 π0.5 上用三组对照拆解这个问题。

- **绝对位姿是否成了动作线索？** 先只遮蔽策略输入中的末端 XYZ 和 6D 姿态，保留图像、指令和夹爪开度。两组策略使用相同的动作标签，整段 50 步动作都以观测时的实测位姿解码，比较杯子平移或抬高后的抓取成功率。
- **动作应该在哪个坐标系表达？** 固定策略输入和动作段起点，分别沿基座轴和夹爪局部轴表达位移。改变夹爪初始朝向，检验策略能否把腕部画面中的目标方向转换成正确的接近动作。
- **看准目标，是否就能抓准？** 在相同的位姿输入条件下，分别加入腕部目标热力图监督和 VGGT 几何特征对齐。把图像定位误差、闭爪前的对齐偏差和最终抓取成功率分开记录，判断空间监督具体影响哪一步。
